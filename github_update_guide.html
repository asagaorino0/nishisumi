🌐 サイト更新マニュアル

西成住之江支部 ポータルサイト｜担当者向け手順書

https://matsuba-commits.github.io/nishisumi/

📋 更新の全体の流れ（5分でできる）

1
Google スプレッドシートを開く
2
イベントを1行追加・修正する
3
数分後にサイトを見て確認する

STEP 1 — スプレッドシートを開く

1
Google スプレッドシートを開く
担当者はイベント管理用の Google スプレッドシートを開きます
📸 Google スプレッドシートの一覧画面
GitHub や HTML ファイルは触りません。更新は表への入力だけです。

STEP 2 — 行を追加する

2
イベントを1行追加または修正する
1行が1イベントです。日付・区分・タイトル・詳細・リンクURLなどを入力します
📸 入力用シートの画面
日付は YYYY-MM-DD 形式で入力する
非表示にしたい行は「公開」列を FALSE にする

STEP 3 — 自動反映を待つ

3
保存は自動
Google スプレッドシートは自動保存されます。追加の保存ボタンは不要です
📸 自動保存表示の画像
GitHub へのアップロード作業はありません。

STEP 4 — 公開ページを確認する

4
数分後にサイトを開く
以下のURLを開いてイベント一覧を確認します
https://matsuba-commits.github.io/nishisumi/
1〜2分後にサイトに反映されます。反映前はキャッシュをクリアして確認してください（Ctrl＋Shift＋R）

確認用URL

5
サイトを確認する
https://matsuba-commits.github.io/nishisumi/
index.html → トップページ
group.html → 小グループ会ページ
report.html → 活動報告ページ
admin.html → 現在のデータ元とイベント内容の確認

困ったときは

トムに相談する
イベントの追記・修正は Google スプレッドシートで対応可能
レイアウト変更やページ追加は開発者対応
Google スプレッドシートの公開設定は初回のみ開発者対応
日々のイベント更新は GitHub ではなく Google スプレッドシートだけ触れば済む構成を目指します。

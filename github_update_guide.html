活動報告 スプレッドシート更新マニュアル

西成住之江支部 ポータルサイト｜担当者向け手順書

更新の全体の流れ（5分でできる）

1
活動報告用の Google スプレッドシートを開く
2
1行追加して、本文と写真リンクを入力する
3
自動保存後に活動報告ページを確認する

STEP 1 — シートを開く

1
活動報告のスプレッドシートを開く
更新担当者は、活動報告用の Google スプレッドシートを開きます。ブックマークしておくと毎回迷いません。
ここに「活動報告シートを開く画面」のスクリーンショットを入れる
例: Google Drive 一覧、またはシート下部の「活動報告」タブが見える画面
GitHub や HTML ファイルは触りません。日々の更新はスプレッドシートだけで完結します。

STEP 2 — 1行追加して入力する

2
新しい活動報告を1行追加する
1行が1件の活動報告です。直前の行をコピーして下に貼り付けると、式の列もそのまま引き継げるので安心です。
ここに「新しい行を追加して入力する画面」のスクリーンショットを入れる
例: 既存行をコピーして、その下の行に新しい内容を入れている画面
日付は YYYY-MM-DD 形式で入力します
visible は 公開、 公開 を選択します
式が入っている列を空白のまま新規作成すると、画像URLが自動生成されないことがあります。迷ったら前の行をコピーしてください。
列名 入力する内容 例
date 開催日 2026-05-19
category 区分 小グループ会 / 支部行事
title 見出し G1小グループ会 第1回 自社紹介・経営課題共有
text 本文 開催内容を2〜4文程度で入力
place 会場名 懐石料理「徳」住之江本店
keywords キーワードをカンマ区切り G1,自社紹介,課題共有
imageAlt 写真の説明文 G1小グループ会の集合写真
担当者が入力する列
date
category
title

driveShareUrl

visible
基本的に触らない列
imageFileId は共有リンクから自動抽出
imageUrl は自動生成
previewImage はシート内プレビュー用
これらの列の式を消すと、写真がサイトに出なくなることがあります
この手順なら迷いません
前の行を丸ごとコピーする
date から imageAlt まで必要な内容だけ書き換える
driveShareUrl に写真リンクを貼る
visible を TRUE にする
式が入っている列は、数式が残っているかだけ確認する

STEP 3 — 写真リンクを入れる

3
Drive 共有リンクを貼る
写真はシートに直接貼り込まず、Google Drive の共有リンクを driveShareUrl 列に入力します。
ここに「Drive の共有リンクをコピーする画面」のスクリーンショットを入れる
例: 「共有」ダイアログで「リンクを知っている全員が閲覧可」が見える画面
Drive 側は「リンクを知っている全員が閲覧可」にします
imageFileId と imageUrl はテンプレートの式で自動生成されます
previewImage はシート内確認用なので、式が入っていれば編集不要です
画像をシートに直接挿入してもサイトには表示されません。必ず共有リンクを貼ってください。
共有リンクを貼ったあと、previewImage に画像が見えればほぼOKです。

STEP 4 — 保存と反映を待つ

4
保存ボタンは不要
Google スプレッドシートは自動保存されます。入力が終わったら、そのままで大丈夫です。
ここに「保存しました」表示のスクリーンショットを入れる
例: 画面上部に「保存しました」または自動保存の表示が出ている画面
GitHub へのアップロードやコミット操作はありません。1〜2分ほどでサイトに反映されます。

STEP 5 — 公開ページを確認する

5
活動報告ページを開いて確認する
数分後に以下の URL を開き、追加した活動報告が表示されているか確認します。
画像つきで確認したいときは report.html を開く
設定や読込状況を確認したいときは admin.html を開く
すぐに反映されないときは、ブラウザ再読込を試してください。まだ出ない場合は 1〜2分待って再確認します。

公開前チェック

タイトルが途中で切れていない
本文が意図した内容になっている
写真が表示されている
誤って非公開の FALSE になっていない
日付が正しい順で表示されている

確認用URL

確認ページ
report.html → 活動報告ページ本体
admin.html → 現在どのデータ元を読んでいるかの確認ページ
index.html → トップページ上の最新表示確認

困ったときは

次の切り分けで確認する
文字修正や活動報告の追加は、まずスプレッドシートを修正する
写真が出ないときは Drive の共有設定と driveShareUrl を確認する
画像プレビューが出ないときは、前の行の数式が残っているか確認する
見た目変更やページ追加は開発者対応
運用担当者は「シートを更新する」ことに集中し、サイトの仕組み変更は切り分けると続けやすくなります。
